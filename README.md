# GrownUp

GrownUp is an interactive prototype for an investment product case study: "Designing for the Gen Z Investor".
It focuses on providing a modern, coherent, and product-driven experience for young, first-time investors.

## Overview

The core problem this product attempts to solve is how to make a first-time young investor feel confident enough to understand, start, and continue investing. 
It replaces traditional dashboard noise with guided clarity, helping users build long-term financial habits.

## Features

- **Mobile-First Experience**: A responsive design built primarily for mobile interaction, presented within a scalable desktop showcase shell.
- **Guided Onboarding**: An interactive onboarding flow to determine the user's starting point and risk comfort level.
- **Contextual AI (GrownUp AI)**: Integrated AI assistance to explain financial concepts in plain language.
- **Money Fitness**: A gamified tracker to encourage consistent investing habits and monthly SIP contributions.
- **Social Discovery**: "Trending in your Circle" feature to discover what peers are investing in.
- **Educational Content**: "Learn without the noise" section designed for quick, clear financial education.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Zustand (State Management)
- Lucide React (Icons)
